Submission Guidelines

We welcome manuscripts from student researchers, independent quants, and undergraduate academics.

Submission Requirements:

  1. PDF Manuscript: Formatted using LaTeX (standard double-column academic template preferred).
  2. GitHub Repository: A public repository link containing clean, documented code and instructions to replicate results.
  3. Abstract: Maximum 250 words summarizing problem, methodology, and empirical findings.

Send your manuscript and repository links directly to: arbenginelabs@gmail.com
